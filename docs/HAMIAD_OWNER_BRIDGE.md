# واسط ورود مالک به همیاد

مسیر: /hamiad/ در وب‌سایت Dentistry1402TUMS؛ فقط نقش canonical مالک می‌تواند فرم را ببیند یا API را فراخوانی کند.

- فرم ورود از UI موجود account/bot-link و فایل CSS مشترک استفاده می‌کند.
- نام کاربری و رمز در HTML، URL، JavaScript، log یا storage ثبت نمی‌شوند؛ کاربر آن‌ها را در فرم وارد می‌کند.
- دریافت صفحه ورود همیاد و کپچا با session cookie و anti-forgery token سرور انجام می‌شود. پاسخ ابتدایی ۳۰۷ آرون با کوکی موقت و تکرار محدود GET مدیریت می‌شود.
- ارسال POST فقط بعد از کلیک صریح، بررسی توکن ضد CSRF مالک و کپچای تازهٔ همان نشست است.
- پس از ورود موفق، پاسخ /my/ مجدداً بررسی می‌شود و تنها کوکی‌های نشست با AES-256-GCM در storage خصوصی hamiad/owner-session.json ذخیره می‌شوند؛ دادهٔ قدیمی نوید بدون تغییر باقی می‌ماند.
- خطای ورود، گذشت پنج دقیقه، کاربر غیرمالک و نقص ساختار صفحه fail-closed هستند. محدودیت تعداد تلاش برقرار است.
- این قابلیت فعلاً دریافت دوره‌ها/پاورپوینت‌ها را انجام نمی‌دهد؛ اتصال تأییدشده، پیش‌نیاز پیاده‌سازی آن در مرحله بعد است.
- آزمون هدفمند: php scripts/test_hamiad_bridge.php. در production باید حالت بدون کوکی (عدم دسترسی)، نشست معتبر مالک و دریافت واقعی کپچا تست شوند.
