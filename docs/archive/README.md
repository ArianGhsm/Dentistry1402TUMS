# Historical implementation records

Files under `docs/archive/` are retained as provenance only. They describe completed migrations, frozen branches, integration waves, or release evidence from a specific point in time.

They are **not current development or deployment instructions**. Current operational authority remains:

- `AGENTS.md` for repository invariants;
- `docs/DEVELOPMENT_WORKFLOW.md` for source-development workflow;
- `DEPLOY.md` for production release rules;
- current domain/runtime documentation outside `docs/archive/` for product contracts.

Historical branch names and pre-release wording are intentionally preserved inside archived reports.
