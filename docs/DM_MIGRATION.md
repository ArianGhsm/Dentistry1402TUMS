DM Migration (مهاجرت گفتگوهای خصوصی)
=====================================

هدف
----
اسکریپت `scripts/migrate_dm_store.php` برای یک‌پارچه‌سازی شناسه‌های گفتگوی خصوصی (DM) طراحی شده است. شناسه‌های DM به صورت `dm:<a>:<b>` قرار می‌گیرند و اعضا به ترتیب قراردادی (lexicographic) مرتب می‌شوند تا موارد تکراری/موازی حذف شوند.

نکات مهم
---------
- اسکریپت قبل از هر تغییری یک نسخهٔ پشتیبان از `server-only/storage/chat/store.json` می‌سازد (`store.json.bak.YYYYMMDDHHMMSS`).
- اسکریپت پیام‌ها، وضعیت خوانده‌ها و پیوست‌هایی که به گفتگوی قدیمی اشاره می‌کنند را به شناسهٔ جدید منتقل یا به شناسهٔ هدف ادغام می‌کند.
- اسکریپت تلاش می‌کند داده‌ها را محافظه‌کارانه ادغام کند و از بازنویسی داده‌های مهم جلوگیری کند.

نحوهٔ اجرا
-----------
از ریشهٔ پروژه اجرا کنید:

php .\scripts\migrate_dm_store.php --apply

اگر `php` نصب نباشد، ابتدا PHP CLI را نصب کنید یا اسکریپت را روی سیستمی که PHP دارد اجرا کنید.

ملاحظات ایمنی
--------------
- قبل از اجرای روی هاست زنده، خروجی و فایل پشتیبان را بررسی کنید.
- این اسکریپت روی نسخهٔ محلی `server-only/storage/chat/store.json` اجرا می‌شود؛ طبق قرارداد پروژه، آپلود مستقیم داده‌ها به هاست باید با احتیاط و مراحل پشتیبان/تأیید انجام شود.

خروجی
-------
اسکریپت پس از اجرا مسیر بکاپ و فهرست گفتگوهای تغییر یافته را نشان می‌دهد.
