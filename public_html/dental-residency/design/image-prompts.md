# Dental Residency Image Prompts

These prompts are placeholders for future original bitmap assets. They must produce new artwork only and must not imitate any competitor brand, layout, mascot, icon set, or color identity.

## Hero Illustration
Create an original modern Persian RTL education hero illustration for a dental residency exam preparation platform. Use calm blue, violet, cyan, and white tones. Show abstract dental study elements, exam sheets, progress panels, and a focused candidate at a desk. No logos, no copied characters, no red-dominant palette.

## Dashboard Icon Set
Create a coherent original icon set for a dental exam dashboard: question bank, timed exam, progress analytics, saved questions, wrong answers, mock readiness, subject progress. Use simple line icons with blue and purple accents on transparent backgrounds.

## Abstract Background
Create an original abstract blue and purple background for a professional dental exam web app. Use soft layered shapes, subtle depth, and high contrast space for Persian text. Avoid stock-photo style and avoid red branding.

## Empty States
Create original empty-state illustrations for saved questions and wrong answers notebook. Use a calm study-focused visual language with dental education objects and subtle violet/cyan accents. No competitor references or copied motifs.

## Subject Category Icons
Create original subject icons for oral pathology, prosthodontics, endodontics, periodontology, radiology, orthodontics, pediatric dentistry, and oral surgery. Use consistent geometry, transparent background, and blue/purple/cyan palette.
