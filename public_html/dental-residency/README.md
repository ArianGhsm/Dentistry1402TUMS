# Dental Residency

این بخش یک زیرمحصول مستقل برای آمادگی رزیدنتی دندانپزشکی است و از حساب، session، گزینه‌ها و state اصلی Dentistry1402TUMS جدا نگه‌داری می‌شود.

- Frontend: `public_html/dental-residency/`
- Auth مستقل: `public_html/dental-residency/api/auth.php`
- Session مستقل: `drx_residency_session`
- Storage مستقل runtime: `storage/dental_residency/`

الگوهای قابلیت از Medofast برداشت شده‌اند: منوی کارت‌محور، ورود OTP، بانک تست، آزمون‌ساز، کارنامه، امتیاز/کوین، مرور فاصله‌دار، بوکمارک، یادداشت، هایلایت، برنامه روزانه و جستجو. محتوای نمونه داخل repo رسمی یا اختصاصی نیست و فقط برای نمایش محصول است.

برای تغییرات بعدی، اول `public_html/dental-residency/AGENTS.md` را بخوان.
